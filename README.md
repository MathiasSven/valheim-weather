# Valheim Weather

Weather and wind forecast for every biome in [Valheim](https://www.valheimgame.com/).

**Live site: https://patrix87.github.io/valheim-weather/**

## Features

- Weather and wind strength for every biome, for any day
- Wind direction and global wind strength over the day
- Live tracker: press **Start day** when the "Day N" popup appears and follow the current weather in real time
- Drag the green marker to adjust the current time; press **Slept → next day** after sleeping

## Running locally

No build step. Open `index.html` in a browser.
